# Security Policy

## Supported Versions

| Version | Supported          |
|---------|--------------------|
| 1.x     | :white_check_mark: |

## Reporting a Vulnerability

If you discover a security vulnerability, please report it **privately** instead
of opening a public issue.

1. Go to the **Security** tab of the repository and use
   **"Report a vulnerability"** (GitHub private vulnerability reporting), or
2. Email the maintainers directly.

Please include:

- A description of the vulnerability and its potential impact.
- Steps to reproduce, if possible.
- The affected version(s).

We will acknowledge your report as soon as possible and work with you on a fix
and coordinated disclosure.

> Note: this tool shells out to the `usbipd` CLI and requires administrator
> rights by design. Please make sure you only use it with a trusted
> `usbipd-win` installation.
